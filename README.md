## About

and The selection sort algorithm is named so for the way it works -  it repeatedly searches an unsorted dataset and **selects** the smallest element from it and gives it a place in the front of the dataset. The beauty of selection sort is it's simplicity.  Though not the most efficient algorithm when it comes to sorting large datasets, its simplicity and clarity is extremely effective for sorting small datasets where the overhead of more complex algorithms isn't justified. In this module, lets learn what a selection sort algorithm is and how to implement it using Java code.
